# Security Policy

## Supported versions

Until `1.0.0`, security fixes are applied to the latest released minor version.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature in this repository. If that feature is
not available yet, contact Piensa IT privately through the contact channel
listed on the organization's GitHub profile.

Include the affected version, a minimal reproduction, potential impact, and any
suggested mitigation. We will acknowledge the report and coordinate disclosure
after evaluating it.
